# Changelog

## 0.1.0-preview.20261120.8 — 2026-11-20

- The launcher now checks and installs updates automatically. Select **Play** when it is ready to open the game menu.
- Solo play starts with Kusti and Starter 1846 at Rappavere.
- Steam menu options are deferred to Phase 2. Direct hosting and joining are available from the game menu.
- Rappavere's offline Class S opponents use a trained traffic model that brakes earlier and leaves more room while racing side by side.

## 0.1.0-preview.20261119.7

- Updated the driving menus and Tab race roster to match the Le Mows interface design. Use the same display name in solo and multiplayer from Settings.
- Reworked the Estonian and English starter calls to follow the race countdown. The starter report sounds on Green.
- Tuned the driving mix so the nearby engine stays clear and track ambience returns as you slow down or get off.
- Improved AI clearance checks and added a reversing maneuver for blocked tractors.
- Refined Starter 1846's steering and impact response. Trackside props use their normal collisions without acting as tyre support.

## 0.1.0-preview.20261115.6

- Added **LeMowsSetup.exe**: choose a folder and install the game with a graphical setup.
- Added a native desktop and Start menu launcher with **Install**, **Update** and **Play**.
- Added visible download/file-verification progress and retry handling.
- The launcher remembers language, play mode and join address.
- Updates verify signed packages and retain known healthy versions for recovery.
- Gameplay remains the current driving/multiplayer prototype; this update changes installation and distribution.

## 0.1.0-preview.20261115.4

- Published the Windows driving prototype and signed player update channel.
- Added verified startup and release compatibility checks.
- Tractor driving, camera views and prototype multiplayer/race control are available for testing.
