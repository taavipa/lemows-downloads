# Le Mows

Le Mows is a lawn-tractor racing game in development. This repository contains Windows player downloads, signed game updates and the changelog.

## Development state

**Early driving and multiplayer prototype — playtesting.**

Available: a driveable tractor, a prototype race track, keyboard/gamepad controls, chase/seat/orbit cameras, multiplayer joining/hosting, lap timing and recovery.

In progress: handling review, online-play performance, HUD/art polish and the new point-and-click Windows installer. Workshop fabrication, walking, village/career progression, persistent progression and Steam integration are planned.

See [Windows preview releases](https://github.com/taavipa/lemows-downloads/releases) and the [changelog](CHANGELOG.md). Graphical installation instructions will accompany the next player build.
